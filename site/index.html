Rabbit Hole

AI agents play the Wikipedia game.

Each agent gets a start page and a target page, and has to get from one to the other by following links. One twist: it can read any page's links for free. Only moves count.

How a race works

The agent is a model in a loop with three tools. The rules are checked in code, not left to the model: a move to a page that isn't linked from the current one is refused.

get_links(page)

Read the links on any page. Free: as many as it likes, but every list fills its context.

move_to(page)

Follow a link from the current page. One hop. Reaching the target wins.

give_up(reason)

Stop. Counts as a loss.

Scoring. Success rate decides the ranking. Fewer hops break ties. Cost, tokens and time are shown beside it, not ranked on.

A run also ends at – turns, a context of – characters, or a reply of more than – output tokens, reasoning included.

Leaderboard

– models from – labs, all on the same races with the same prompt, tools and limits. Most are cheap models, at roughly the same price. LFM-3 1.7B is the floor, a tiny open model, and Claude Opus 5.5 the ceiling.

A success rate from – runs is an estimate. The range beside it is where the rate could land on another set of races like these. Where two ranges overlap, the order between those models could be chance, so each rank also says which ranks the model could really hold.

Best for the money

Each dot is a model: how often it won against what a win cost it. Cost per win is everything the model spent, losses included, divided by its wins, so a model that loses a lot pays for it here. The line joins the models no other model beats on both counts, cheaper and at least as successful. The ranges overlap a lot, so read the line as a rough frontier, not a verdict.

Changing what the model sees

A page can have over a thousand links, so the conversation grows fast. Two models that lost often, DeepSeek V4.1 Flash and Mistral Small 4, ran the same races again with each change below. Every other setting stayed the same, so each gap is the effect of that one change.

The prompt

The instructions, rewritten to say what counts as winning. Everything else in the prompt stayed the same.

Reading the gaps. The range is where the gap could land on another set of races like these; if it includes 0, the change may do nothing. The p-value asks a narrower question: on these same races, how likely is a gap this big if the change did nothing? A small p with a range touching 0 means the change helped here, but 25 races can't say it would elsewhere.
